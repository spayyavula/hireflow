## A note on `?src=` tags on X

The [2026-05-21 X launch draft](2026-05-21-x-launch.md) warned against
tracking parameters on the grounds that X may suppress reach. That was
written before migration 010 added the `source` column. The tradeoff has
flipped:

- **Without tags:** zero attribution. Can't tell whether the X thread
  drove anything vs. the LinkedIn post.
- **With tags:** small theoretical reach risk (the actual evidence for
  this in 2026 is thin), full attribution.

At this stage, attribution wins. If a future X thread underperforms
relative to a prior un-tagged one, revisit. For now, ship with tags.

### Tag table

| Tag | Where it appears | What it measures |
|---|---|---|
| `x2` | Bare hyrly.ai link in Tweet 4 | Top-of-funnel; "tell me more" clickers |
| `x2-sev` | Severance calculator link | Mid-negotiation cohort — highest intent |
| `x2-h1b` | H-1B landing page link | H-1B cohort — measures whether visa angle wedges differently on X vs LinkedIn |

`x2` deliberately mirrors `li2` so you can compare cross-platform
performance directly: `triages WHERE source = 'x2'` vs `WHERE source =
'li2'` tells you which audience converts harder for the same hook.

### Funnel query (paste into Supabase SQL Editor)

```sql
SELECT t.source,
       COUNT(t.id)                                AS triages,
       COUNT(DISTINCT s.id)                       AS scout_sessions,
       COUNT(DISTINCT s.id) FILTER (
         WHERE jsonb_array_length(s.messages) >= 4
       )                                          AS scout_engaged
FROM triage_responses t
LEFT JOIN scout_sessions s ON s.triage_id = t.id
WHERE t.source LIKE 'x2%' OR t.source LIKE 'li2%'
GROUP BY t.source
ORDER BY triages DESC;
```

Reading this query: any source tag with `scout_engaged ≥ 1` is a
channel that produced a real user. If only `li2*` shows engaged
sessions and `x2*` is all top-of-funnel triages with no chat-through,
LinkedIn's audience is more bought-in even at lower volume — that
informs where the next swing's effort goes.

## What success looks like at this scale

X has lower per-impression conversion than LinkedIn for this ICP but
higher reach ceiling, so the metric mix is different:

- **Tweet 1 impressions ≥ 1,000 in 24h** — the bare-minimum signal that X surfaced it to anyone outside your direct followers.
- **3+ replies from accounts you don't follow** — cold-audience pickup, the X equivalent of an outside-network LinkedIn reshare.
- **2+ triages tagged `source LIKE 'x2%'`** — proves the thread → click → triage path works at all on X.
- **1+ engaged scout session tagged `source LIKE 'x2%'`** (≥ 4 messages) — proves an X user converted all the way through, not just clicked.
- **1+ RT from an account >1,000 followers** — the X equivalent of a mid-tier LinkedIn share; opens the next reach tier.

If 3 of these 5 happen, X is a viable second channel for Hyrly. If
fewer than 2 happen, X is not the right early-stage channel and effort
should consolidate on LinkedIn + organic playbook SEO instead.

## Anti-patterns

- **Don't** post the LinkedIn copy verbatim. The "I'll drop the link in the first comment" line makes no sense on X (no comment-pinning mechanic, links in thread are fine). Use the X thread as written.
- **Don't** add hashtags. X actively suppresses hashtag-heavy posts in 2026; the contrarian hook is enough.
- **Don't** tag specific accounts in the thread without pre-agreement. Algorithm penalty if they don't engage, and burns goodwill.
- **Don't** delete and re-post if Tweet 1 underperforms in the first hour. X's algorithm pattern-matches that as inauthentic and depresses the next attempt too.
- **Don't** add a 5th tweet that asks for RTs. The "Tell a friend who needs it" line in Tweet 4 already does this with less salesmanship.
